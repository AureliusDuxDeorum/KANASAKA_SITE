Install notes

KS_Link is in active alpha development. The Windows build self-updates in-app once installed (Settings → Account → Check for updates).

  • iOS: not available yet. A build is planned but there is no release to download.
  • Android: self-signed alpha build. Enable sideloading or install via ADB; Android will warn because the build is not signed with a Play Store key.
  • Windows: you may see a SmartScreen warning because the installer is not code-signed. Choose “More info”, then “Run anyway”.
  • Linux: install the .deb with sudo dpkg -i KS_Link.deb or the .rpm with sudo rpm -i KS_Link.rpm. The AppImage only needs chmod +x and runs without installing.
