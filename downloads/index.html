Install notes

KS_Link is in active alpha development. Early builds may change quickly between releases, and the Windows build self-updates in-app once installed (Settings → Account → Check for updates).

  • iOS — Not available yet. A build is planned but there's no release to download.
  • Android — Self-signed alpha build. Enable sideloading or install via ADB; Android will warn because the build isn't signed with a Play Store key.
  • Windows — You may see a SmartScreen warning because the installer is not code-signed. Choose "More info", then "Run anyway".
  • Linux — Install the .deb with sudo dpkg -i KS_Link.deb or the .rpm with sudo rpm -i KS_Link.rpm. The AppImage just needs chmod +x and can run without installing.
