Changelog

What changed on kanasaka.com, release by release.

1.6.9

2026-11-07
  • NewKS_Link sign-in can now finish without the browser having to start the app again, which fails when the app is already running. The browser confirms the sign-in and the running app picks it up on its own.

1.6.8

2026-11-06
  • FixedThe Search button in the header no longer wraps onto two lines on mid-size desktop windows. The menu button now takes over at 1,320 px and below, and the header spacing is slightly tighter.

1.6.7

2026-11-06
  • ImprovedWhen signing in to link KS_Link, the page now checks the hand-over first and shows the reason if the app cannot be opened, instead of failing silently.

1.6.6

2026-11-06
  • FixedSigning in or registering to link KS_Link now returns you to the app. A confirmation screen with an Open KS_Link button appears while the browser hands over.
  • FixedRegistration could fail with a Terms error when a browser held an outdated copy of the site scripts. Script and style files now carry a hash of their content, so a changed file is always fetched fresh.
  • FixedThe six-digit code boxes on phones are square and sized so the digits fit.
  • ImprovedThe Cookie Policy now lists everything the site stores in your browser and states the session cookie’s lifetime (effective 6 November 2026).

1.6.5

2026-11-06
  • FixedThe FAQ, the KS_Link page, the Security page and the System status page now match the current terms: a KS_Link account is a KANASAKA account, KS_Social is built into the app, and conversation history stays on your device.
  • NewTwo new FAQ answers: where your message history is stored, and how to delete a KS_Link account.

1.6.4

2026-11-06
  • NewThe header now says “Search” next to the // so it is clear that it opens the site search.
  • ImprovedOn phones the header is a single row about half as tall: Log In and Register moved into the menu, and the header slides away while you scroll down and returns when you scroll up.

1.6.3

2026-11-06
  • ImprovedThe home hero is drawn on a canvas and only redraws the characters that change, so it runs smoothly on tablets.
  • NewAdding ?hero=debug to the home page address shows a diagnostics panel with frame timings and switches, for troubleshooting slow devices.

1.6.2

2026-11-06
  • FixedThe home hero animation could stop a few seconds after loading on slower devices. Its speed check now waits until the page has settled, ignores short stalls, and gives the animation a second chance when you return to it. The readout beside the hero shows the current rate or STATIC.

1.6.1

2026-11-06
  • NewKeyboard shortcuts: Ctrl+K and / open the terminal, Ctrl+B replays the boot sequence, Ctrl+Y cycles the theme, Ctrl+H goes home and Ctrl+J goes to Downloads. They do nothing while you type in a field. The keys command lists them.
  • ImprovedThe boot sequence started from the terminal or with Ctrl+B is a longer variant of about five seconds, with more readout lines and a progress bar.
  • ImprovedThe terminal now closes with its × button; Esc and Ctrl+K no longer close it.

1.6.0

2026-11-05
  • NewThe header and footer are part of every page's HTML, so navigation appears immediately and works without JavaScript.
  • NewFAQ, live system status, a support overview and this changelog.
  • NewPage descriptions, share previews (Open Graph and Twitter cards), a sitemap, and a proper “page not found” page.
  • ImprovedSource, configuration and documentation files from the repository are explicitly not served by the website.

1.5.4

2026-11-05
  • ImprovedThe home hero no longer reacts to the cursor or to taps; the pointer ripple and its readout are gone.

1.5.3

2026-11-05
  • ImprovedThe ASCII hero now runs on one fixed 15 Hz tick instead of an adaptive rate, so it looks deliberately paced next to the rest of the page.

1.5.2

2026-11-05
  • FixedTablets were being run in Reduced motion; only the data-saver setting lowers motion now.
  • ImprovedStronger animations, and recommendations in the terminal that need an account are marked “Account necessary” for visitors who are signed out.
  • NewA boot command in the terminal replays the boot sequence.

1.5.1

2026-11-05
  • NewThe KS_Site terminal: the // in the header opens a command-prompt style search window with directory-style commands and recommendations.
  • ImprovedCleaner terminal design that follows the site's theme colours.

1.5.0

2026-11-05
  • NewMotion layer: staged reveals, heading decode, a nav indicator, a scroll progress line, live readouts in the footer and hero, a boot sequence and page transitions between pages.
  • NewA grid floor, scan sweep and hero scan band; the Accent theme adds glitch effects on top.
  • ImprovedMotion respects the system “reduce motion” setting and can be set to Automatic, Full, Reduced or Off.

1.4.3

2026-11-05
  • ImprovedThe home statement is set in capitals.

1.4.2

2026-11-05
  • ImprovedThe home statement now reads “A new era of evolution.”

1.4.1

2026-11-05
  • FixedThe Products, Company and Legal labels in the menu now open their overview pages instead of only selecting the button.

1.4.0

2026-11-05
  • NewA shared design system and redesigned key pages.
  • ImprovedThe navigation and footer list only pages that exist.
  • ImprovedThe Alpha tag uses the KANASAKA purple, and the Accent theme is darker and uses the purple sparingly.
  • ImprovedProducts that are still in development are no longer mentioned.

1.3.1

2026-11-03
  • ImprovedSmoother product strip on the home page, with lighter images and a lighter footer.

1.3.0

2026-11-03
  • ImprovedSecurity hardening: stricter limits on sign-in and one-time-code attempts, rate limits on email endpoints, a global cross-site request check and security headers on every API response, and internal errors no longer reach the browser.
  • FixedOne-time codes and sessions could stay valid for longer than intended after their expiry time.
  • ImprovedThe Content Security Policy no longer allows inline styles, and the site publishes a security.txt.

1.2.0

2026-11-03
  • ImprovedThe home hero shows the KS logo horizontally on desktop and tablet, and vertically on phones.

1.1.1

2026-11-03
  • ImprovedThe menu button is three stacked bars instead of the word “Menu”.

1.1.0

2026-11-03
  • ImprovedThe hero table is gone and the hero characters flip instead of waving.
  • NewA // page mark in the corner of pages, and icons in the account settings.

1.0.0

2026-10-31
  • NewFirst tagged release of the website.
