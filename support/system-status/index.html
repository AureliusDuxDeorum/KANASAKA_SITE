What this shows

A live check, not a record

Each check runs when you open this page: the account database answers a trivial query and the downloads bucket answers a lookup. The result is a yes or a no, nothing more.

  • No uptime history

    Nothing is stored between checks, so there is no uptime percentage and no incident log, and no service-level agreement is offered.

  • KS_Link has its own relay

    KS_Link signs you in with your KANASAKA account, so the account checks above apply to it. Messaging and social run on KS_Link's own relay, which this page does not report on.
